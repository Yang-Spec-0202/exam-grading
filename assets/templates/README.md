# 全国卷数学模板包（内置模板数据）

> 状态：v0.1 · 2026-11-02 · 归属模块：`rubric`（`eg-rubric`）
> 对应规范：`SPEC-rubric.md` v0.2.1 §2.2/§2.4/§3.5、`SPEC-domain.md` v0.2（`Rubric`/`RubricItem`/`ScoringMode`/`QuestionKind`）、`CONFIG.md` §7
> 来源与置信度：`docs/dev/research/templates.md`

本目录是**随包内置、只读、按卷型版本化的全国卷数学模板数据**。模板只描述「试卷结构 + 分值 + 通用评分项骨架」，**不包含任何题目原文**，也不等同于官方评分细则。

## 1. 目录与文件

```text
assets/templates/
├── README.md                         # 本文件：格式、字段、版本、校验规则
└── national/
    ├── new-curriculum-1/template.toml   # 新课标Ⅰ卷（现行）
    ├── new-curriculum-2/template.toml   # 新课标Ⅱ卷（现行）
    ├── national-jia/template.toml        # 全国甲卷（历史卷，2026 起停用）
    └── national-yi/template.toml         # 全国乙卷（历史卷，2024 起停用）
```

- 文件格式：TOML（UTF-8，无 BOM），`schema_version = 1`。
- 目录名 `set-id` 与 `set_id` 字段一致；`[[questions]]` 顺序即卷面顺序。
- 新增卷型 = 新增 `national/<set-id>/template.toml`，不改动既有目录。

## 3. 分值单位与折算规则

为与 `SPEC-domain.md` 的 `MilliScore` 一致，模板内所有分值一律用**千分之一分的整数**表示，禁止浮点：

| 字段 | 单位 | 例 |
|---|---|---|
| `total_score_milli` | 千分之一分 | `150000` = 150 分 |
| `max_score_milli`（每题） | 千分之一分 | `5000` = 5 分；`13000` = 13 分 |
| `ratio_permille`（骨架评分项） | 千分比 | `300` = 该题满分的 30% |

**骨架折算规则**（套用模板生成草稿时）：

1. 单项分值 = `题目 max_score_milli × ratio_permille / 1000`；
2. 结果必须落在 0.1 分（= 100 千分之一分）网格上，否则视为模板数据错误（加载期显式失败）；
3. 同一题目内折算后合计必须 **等于** 题目满分（本包所有骨架的 `ratio_permille` 合计为 1000‰），不得静默归一化或四舍五入抹平差额；确需调整时由教师手工改分值并重跑校验；
4. `rubric.min_score_granularity` 取 `0.1`（默认）时本包全部骨架可直接折算；取 `0.5` 或 `1` 时，部分骨架步骤（如 3.9 分）会低于粒度，静态校验按规范报错误级，**由教师调整**，模板不做自适应。

本包所有比例均为 100‰ 的整数倍，保证整数满分题目在 0.1 分粒度下可精确折算（如 13 分 × 300‰ = 3.9 分）。

## 4. 字段定义

### 4.1 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schema_version` | 整数 | 是 | 模板文件格式版本，当前恒为 `1`；不兼容变更时递增 |
| `template_id` | 字符串 | 是 | 模板稳定标识（全局唯一，只追加不改名），进审计与判分复现 |
| `set_id` | 字符串 | 是 | 卷型标识，与目录名一致 |
| `display_name` | 字符串 | 是 | 中文卷型名，须与 `CONFIG.md` §7 `rubric.national_sets` 的取值一致 |
| `subject` | 字符串 | 是 | 学科，v1 恒为 `math` |
| `paper_style` | 枚举 | 是 | `new-gaokao`（新高考）或 `old-gaokao`（老高考） |
| `status` | 枚举 | 是 | `active`（现行卷）或 `retired`（历史卷，仅供历史试卷套用） |
| `retired_since` | 整数 | `retired` 时必填 | 停止使用的年份（该年起不再命制） |
| `version` | 字符串 | 是 | 模板版本，格式 `<snapshot_year>.<修订号>`，见 §7 |
| `snapshot_year` | 整数 | 是 | 模板所依据的试卷年份快照 |
| `snapshot_label` | 字符串 | 是 | 面向教师的结构快照说明 |
| `total_score_milli` | 整数 | 是 | 全套总分（千分之一分），必须等于各题 `max_score_milli` 之和 |
| `question_count` | 整数 | 是 | **作答题目数**（合并的二选一选做题只计一条），必须等于 `[[questions]]` 条数 |
| `printed_max_ordinal` | 整数 | 否 | 卷面最大题号；仅当存在合并的二选一选做题时填写（如甲/乙卷为 23，而作答 22 条） |
| `structure_note` | 字符串 | 是 | 题型与分值分布的一句话说明，供界面展示 |
| `structure_confidence` | 枚举 | 是 | 题量/题型/各题型总分置信度：`high` / `medium` / `low` |
| `score_split_confidence` | 枚举 | 是 | 逐题分值置信度：`high` / `medium` / `low`（与结构置信度分开，避免把推定值当官方值） |

### 4.2 `[[questions]]`（题目）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ordinal` | 整数 | 是 | 卷面顺序，从 1 起**连续**；模板内唯一 |
| `label` | 字符串 | 是 | 题号显示文本；合并的二选一选做题写 `22/23` 这类形式；小题可写 `17(2)` |
| `kind` | 枚举 | 是 | 必须取自 `SPEC-domain.md` 的 `QuestionKind`：单选/多选/判断/填空/纯数值/计算/解答/证明/简答/论述/其他 |
| `max_score_milli` | 整数 | 是 | 本题满分（千分之一分），必须为正 |
| `skeleton` | 字符串 | 是 | 引用本文件 `[skeletons.<id>]` 中的骨架 id |
| `kind_note` | 字符串 | 否 | 题型可替换提示（如解答题当年为证明题时改用证明骨架） |
| `choice_group` | 字符串 | 否 | 二选一选做分组 id（如 `22-23`）；同组只计一题，总分不重复累加 |
| `choice_note` | 字符串 | 否 | 合并选做题的套用说明 |

### 4.3 `[provenance]`（来源与免责）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `verified_at` | 字符串 | 是 | 最近一次人工核对的日期（`YYYY-MM-DD`） |
| `confidence` | 枚举 | 是 | 本模板整体置信度：`high` / `medium` / `low` |
| `basis` | 枚举 | 是 | `official`（官方原文可核）/ `public-analysis`（公开资料推定）/ `inferred`（待人工确认的推定） |
| `source_ids` | 字符串数组 | 是 | 引用研究记录 `templates.md` 的来源编号（S1、S2…），保证可追溯 |
| `disclaimer` | 字符串 | 是 | 面向教师的免责声明，须含「不含题目原文」「骨架非官方细则，须教师确认」 |

### 4.4 `[skeletons.<id>]`（评分项骨架）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scoring_mode` | 枚举 | 是 | `累加` / `全对才给分` / `分步给分`，对应 `ScoringMode` |
| `label` | 字符串 | 是 | 骨架名称（界面展示） |
| `scoring_note` | 字符串 | 否 | 该骨架的计分说明与已知限制 |
| `items` | 表数组 | 是 | 评分项列表，长度 1–50 |

### 4.5 `[[skeletons.<id>.items]]`（评分项）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ordinal` | 整数 | 是 | 骨架内序号，从 1 起；`depends_on` 引用此序号 |
| `criterion` | 字符串 | 是 | 通用判据占位文本，以 `【模板骨架】` 开头；不得为空 |
| `ratio_permille` | 整数 | 是 | 占该题满分的千分比，必须为正；同一骨架内合计 ≤ 1000 |
| `required` | 布尔 | 是 | 对应 `RubricItem.required`（是否必须满足才计分） |
| `depends_on` | 整数数组 | 是 | 引用本骨架内更小序号的评分项；必须存在且不得成环；可为空 |
| `placeholder` | 布尔 | 是 | 恒为 `true`：表示判据尚未替换为本题具体判据 |

## 5. 骨架 → 草稿 → 生效规则的链路

1. 教师选卷型 → 系统按 `[[questions]]` 逐题生成草稿项（`DraftOrigin` = 模板套用）；
2. 草稿项 `points` 由 §3 折算得到，`criterion` 仍是 `【模板骨架】…` 且 `placeholder = true`；
3. 静态校验（`SPEC-rubric.md` §2.4）会把「判据仍为模板占位」判为**错误级**，因此模板套用后**不能**直接进入待确认，必须由教师逐题替换判据、按当年评分细则调整分值与依赖；
4. 教师确认后才生成生效 `Rubric`（`RubricOrigin` = 标准模板）。**任何模板都不得绕过确认。**

实现约定（供 `eg-rubric` 落库校验使用）：`placeholder = true` 或 `criterion` 以 `【模板骨架】` 开头，均视为「模板占位文本」，命中「`criterion` 非空且非模板占位」错误级规则。

## 6. 题型与骨架对应

| 题型 | 骨架 | 计分方式 | 说明 |
|---|---|---|---|
| 单选 | `objective-single` | 全对才给分 | 1 个评分项，满分 |
| 多选 | `objective-multiple` | 全对才给分 | 1 个「全对」评分项；部分给分规则见 §10 限制 |
| 填空 | `objective-blank` | 全对才给分 | 1 个评分项，按答案键与等价规则判定 |
| 计算/解答 | `step-compute` | 分步给分 | 通用三步（方法与建模 30% / 过程与中间结论 40% / 结论 30%），默认无依赖 |
| 证明 | `step-proof` | 分步给分 | 通用三步（构造 30% / 推理链 40% / 结论规范 30%），线性依赖 |

- 纯数值、判断、简答、论述、其他：v1 模板包未内置骨架（数学全国卷不涉及）；自定义模板可自行提供。
- 全国卷解答题自 2024 年起**不再按题号固定考点**，故模板统一按「计算/解答」登记；某题为证明题时由教师按 `kind_note` 改用 `step-proof`。

## 7. 版本与状态规则

- **只追加不改写**：`template_id` 与 `set_id` 永久稳定；任何结构、分值、骨架、`display_name` 变化都必须升 `version`，不得原地修改同一版本内容。
- **版本格式**：`<snapshot_year>.<修订号>`，如 `2026.1`。同一年度内修正数据 → 升修订号（`2026.2`）；新一年度试卷 → 新快照年份（`2027.1`）。
- **状态流转**：`active` → `retired` 需升 `version` 并填 `retired_since`；`retired` 模板只读保留，不删除（历史试卷批改需要复现）。
- **历史版本存放**：当前实现约定每个 `set-id` 目录只放当前版本 `template.toml`，历史版本由版本库提交追溯；若后续发行需要随包携带多版本，按 `national/<set-id>/history/<version>/template.toml` 追加（预留约定，当前未启用，属待确认项）。
- **审计**：模板来源（全国卷包）、`template_id`、`version` 写入规则草稿与确认审计，保证判分可复现。
- 修改内置模板属 `SPEC-rubric.md` §7 的 **Ask first**：先提变更、审批通过后再改数据并同步升级提示词版本。

## 9. 来源与免责声明

- **来源分级**（逐条见 `docs/dev/research/templates.md`）：
  - **官方原文**：教育部教育考试院试题评析（含政府/党媒转载的原文）、官方期刊《中国考试》；
  - **公开资料推定**：媒体名师点评、教研机构试卷分析、公开真题解析快照；用于确认题量、题型分布与逐题分值；
  - **待人工确认**：无法从官方原文直接核到的逐题分值、部分给分建模方式、历史卷使用省份等。
- **置信度**：`high` = 官方原文可核；`medium` = 多份独立公开资料一致或官方间接可推；`low` = 单一来源或推断。
- **版权**：本目录**不存储、不转录任何试卷题目原文、选项、答案或解析**；只保留可公开引用的结构与分值元数据。题目原文版权归命题机构所有。
- **免责**：模板数据为工程用结构快照，**不是官方评分细则**，不作为教学或命题依据；分值以当年正式试卷与评分标准为准。项目为求职展示，不承诺持续维护；试卷结构变化时以新快照版本随发行更新。

## 11. 已知限制与待人工确认

1. **多选部分给分未在骨架中自动实现**：2024 年起新课标卷多选「部分选对得部分分」（2 个正确选项选 1 个得 3 分；3 个正确选项选 1 个得 2 分、选 2 个得 4 分；有错选 0 分）。该规则非「累加」可表达，v1 骨架只给「全对」单档，需教师按当年细则改写；是否在 `domain` 增加多选赋分模型属 Ask first（待确认）。
2. **解答题逐题分值为推定**：2024–2025 年为公开资料可核（13/15/15/17/17），2026 年官方评析只公布「19 题 / 150 分」，未逐题公布；模板按「延续 2024–2025」推定（`score_split_confidence = medium`），须人工对照当年试卷确认。
3. **甲/乙历史卷**：甲卷最后使用年为 2025（2026 起退出）、乙卷 2024 起停止命制；甲/乙 17–21 各 12 分、22/23 各 10 分为公开资料推定（`medium`）。
4. **2026 年起卷型整合**：官方评析全文只出现全国Ⅰ卷、Ⅱ卷，未见甲/乙卷；「甲/乙取消」由公开资料一致佐证，官方未使用「取消」字样，属间接结论（`medium`）。
5. **历史版本存放方案**（§7）为预留约定，需与 `rubric` 负责人确认后再启用。
6. **模板不含文/理分科、选考科目组合**：全国卷数学文/理同结构（甲/乙），模板只描述结构，不区分文理内容。
