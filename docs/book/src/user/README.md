## 三条必须先知道的事实

1. **没有登录**。启动即进入工作区；所有审计记录的操作者固定为 `local-teacher`（`SPEC.md` A1）。不要在多台机器上同时打开同一工作区。
2. **文件名就是学生身份**。系统不做 OCR 姓名兜底（默认关闭），文件名未命中名单只会进「未决」，等你在名单里选人（`SPEC-align.md`）。选文件时会提示规范命名。
3. **两种模式的结果不能混着比**。标准模式与快速模式分别统计、分别标注；快速模式结果带「快速」标记并按 20% 比例抽检（`SPEC-grade.md`、`SPEC-report.md`）。快速结果不是正式成绩。

## 术语速查

| 术语 | 含义 |
|---|---|
| 名单 | 班级学生列表（学号、姓名），身份匹配的唯一依据 |
| 答案键 | 教师提供的参考答案；可为具体答案、仅评分标准、明确「略」或缺失 |
| 评分规则 | 结构化评分项与分值；必须教师确认后才生效 |
| 提交 | 一个学生的一次作业（一个源文件；PDF 可多页） |
| 区域 | 页面上某道题的作答范围（模板区域、版面检测或人工框选） |
| 复核 | 对低置信度/抽检/主观题的人工确认或改分 |
| 未决项 | 系统无法自动决定、必须由你处理的事项（身份、区域、缺页、重复等） |

## 手册写作约定

- 命令与路径用行内代码；界面名称随实现可能微调，以实际界面为准。
- 详细字段、阈值、默认值以 `CONFIG.md` 为准；本手册只解释「怎么用」。
- 发现手册与界面不一致时，以规范与发布说明为准，并在项目仓库提文档修订（文档门禁要求用户可见行为变更同步本目录与 `changelog.md`）。
