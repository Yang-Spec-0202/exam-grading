# 成绩导出

> 状态：M10 文档初稿（计划中）。报表页与导出随 M8 实现提供；命名与统计口径以 `SPEC-report.md` 为准。

## 1. 导出前先确认

- 正式成绩只统计「已自动接受 + 已人工复核」的记录；**待复核项不会混入正式成绩**，会在报表中单独列出。
- 缺考、无效提交、重复提交、超范围等由「提交级排除」处理，按原因单列，不参与均分与排名。
- 标准与快速模式分别统计；「全部」只用于对照查看，不产生混合总分。
- 如果刚改过分，导出前请确认没有未复核项；导出后如再改分，需要重新导出。

## 2. 报表包含什么

| 工作表 | 内容 |
|---|---|
| 元信息 | 试卷名、版本（答案键/规则/名单）、模式筛选、口径版本、命名规则版本、批次时间、快照哈希、抽检率与抽样方法说明、脱敏开关 |
| 班级汇总 | 有效样本数、缺考、排除、待复核、名单外；平均分、标准差、最高、最低、及格率、优秀率（标准/快速各一行） |
| 成绩单 | 每生一行：学号、姓名（脱敏时用掩码）、模式、状态、有效满分、得分、折算分、整卷满分、得分率、同模式排名、各题得分 |
| 题目统计 | 每题：标签、题型、满分、样本数、得分率、零分率、未满分率、区分度（标准/快速各一组列） |
| 选项分布 | 选择题各选项人数与占比，含「空」「不确定」 |
| 错题标签 | 按知识点标签统计错题次数、错题率、失分率 |
| 班级分布 | 得分率区间人数与占比（10 箱，末箱含满分） |
| 快速抽检 | 仅快速模式：抽检标记、抽检状态、是否转标准复核 |

口径说明（避免误读）：

- 得分率 = 得分之和 ÷ 满分之和；排除题不计入分子分母。
- 整卷得分率 = 得分 ÷ 有效满分；有效满分小于整卷满分时标「不完整」，并给折算分。
- 区分度采用 27% 高低分组法；样本数 <30 时显示「不适用」。
- 排名是同模式内的竞争排名（1、1、3）；缺考/待复核/排除者不参与排名。
- 分数保留最多 3 位小数；得分率四舍五入到 0.1%；平均分/标准差/区分度保留 2 位小数。

## 3. 三种格式

| 格式 | 用途 | 注意 |
|---|---|---|
| XLSX | 教师日常查看、二次编辑 | 分数学位列可直接排序/筛选；不作为数据交换的权威格式 |
| CSV | 导入其他系统、脚本处理 | UTF-8 带 BOM，Excel 双击不乱码；另附千分之一分整数列与率整数（百万分比）保证无损复算 |
| HTML | 打印、发给同事查看 | 单文件、离线打开、无外部引用；打印样式已内嵌 |

文件命名规则：

| 场景 | 示例 |
|---|---|
| 整卷报表 | `期中数学_标准_20261102-193000.xlsx` |
| 两模式对照 | `期中数学_全部_20261102-193000.xlsx` |
| 学生成绩单 | `张三_期中数学_标准_20261102-193000.xlsx` |
| 脱敏导出 | `期中数学_标准_20261102-193000_脱敏.xlsx` |
| CSV 分表 | `期中数学_标准_20261102-193000_成绩单.csv` |

- 时间戳取导出时刻（工作区时区），并写入元信息，便于重放。
- 文件名中的非法字符会替换为下划线；过长会截断并追加内容哈希前 8 位；同秒同名会追加序号。
- 已存在的文件默认不覆盖；需要覆盖时会二次确认。

## 4. 脱敏导出

- 姓名替换为 `学生01` 这类掩码，学号替换为 `S-001`；不导出答案原文与原始图片路径。
- 掩码按名单学号/姓名稳定排序分配，同一次导出内唯一、重放可复现。
- **注意**：脱敏是去标识化，不是匿名化；持有名单的人仍可能重识别。对外分享前请自行确认。
- 脱敏文件名的学生名也用掩码；试卷名保留（如含班级/教师姓名请改用中性名）。

## 5. 导出是原子的

- 单文件先写临时文件，全部成功后才替换为正式文件；多格式必须全部成功才算成功。
- 中途失败（磁盘满、权限、被占用）会清理临时文件，不会留下半个文件。
- 导出记录包含文件名、模式、口径版本、文件哈希与行数，可在导出历史中查到。

## 6. 重放与复现

- 同一份数据（同一快照）可以重新导出，报表内容应一致；元信息中的快照哈希与口径版本用于确认「是不是同一份数据」。
- 如果判分/复核/排除有变化，快照哈希会变化，重新导出会得到新结果——这是预期行为。
- 重放比较的是内容（单元格、CSV 字节、HTML 文本），不是文件时间戳。

## 7. 性能预期

- 单模式 1000 份 × 20 题的三个格式合计目标：P95 ≤15 秒（M4/16GB）；峰值内存 ≤300MB。
- 导出在后台进行，可取消；取消后不残留临时文件。

## 8. 常见问题

**为什么有学生没有分数？** 可能缺考、名单外、被排除或仍有待复核项；看成绩单「状态」列与班级汇总的计数。

**为什么排名空着？** 缺考/待复核/排除的学生不参与排名。

**快速模式的文件名没有「快速」字样？** 设置里可关闭文件名/表头标注；但元信息、行内模式列与统计分组仍会标注快速模式（模式可分辨不可关闭）。

**CSV 用 Excel 打开中文乱码？** 正常导出的 CSV 带 BOM，不应乱码；若从其他工具另存过，请重新导出。
