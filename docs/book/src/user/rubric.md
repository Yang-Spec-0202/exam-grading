# 评分规则

> 状态：M10 文档初稿（计划中）。规则页随 M5/M9 提供；校验项与模板数据以 `SPEC-rubric.md` 为准。

## 1. 规则从哪来

| 来源 | 流程 | 你需要做的 |
|---|---|---|
| 手写自然语言 | 录入原文 → 直接直译成草稿，或送模型整理成结构化评分项 | 检查整理结果是否符合原意，确认 |
| 全国卷模板 | 选卷型套用 → 生成评分项骨架（判据占位、分值、依赖） | 按本班实际调整分值与判据，确认 |
| 导入文本 | 从 DOCX/CSV 抽取规则文本 → 直译或模型整理 | 同上 |

三条路径最终都产出**草稿**，都要经过校验与你的确认才生效。没有任何路径可以跳过确认。

## 2. 模板包

| 卷型 | 状态 | 说明 |
|---|---|---|
| 新课标Ⅰ卷 | 现行（active） | 可套用到新试卷 |
| 新课标Ⅱ卷 | 现行（active） | 可套用到新试卷 |
| 全国甲卷 | 历史快照（retired，2026 停止命制） | 只读；仅用于历史试卷与历史判分复现，不推荐用于新试卷 |
| 全国乙卷 | 历史快照（retired，2024 停止命制） | 同上 |

规则：

- 模板只提供**结构骨架**（题号、分值比例或固定分值、判据占位、依赖关系），具体判据与分值必须由你确认。
- 模板数据随包内置、只读、版本化；模板状态只允许 active → retired，且需升版本并写审计。
- retired 模板不删除，保证历史试卷可复现；不要用 retired 模板给当年新试卷做默认推荐。
- 自定义模板可以新建或导入；导入包先过格式校验与静态校验，通过后登记为只追加版本。
- 模板缺失或数据不合法时不会套用，会回退到「空草稿 + 手写直译」并提示。

## 3. 模型整理的边界

模型只做「格式整理」：

- 可以：把自然语言拆成评分项、补结构化字段、把分值统一为千分之一分整数。
- 不可以：新增原文没有的判据、修改分值语义、生成或修改答案键、判断学生答案、决定是否生效。
- 整理输入不包含任何学生作答数据。
- 如果整理结果与原文语义冲突（例如原文「每步 2 分」被整理成一次性给分），系统会记错误级校验问题并保留原文，等你在规则页裁决。

## 4. 草稿状态与确认

| 状态 | 含义 | 可做什么 |
|---|---|---|
| 草稿 | 正在编辑 | 修改、送整理、提交确认 |
| 待确认 | 已通过静态校验，等你确认 | 确认、拒绝、继续编辑 |
| 已确认 | 生效，生成规则新版本 | 只读；如需修改请新建版本 |
| 已拒绝 | 终态 | 只读；可重新从原文起草 |

- **确认恒开**：系统不提供「跳过确认」入口；确认人固定 `local-teacher`，确认时间写审计。
- 校验有错误级问题时，确认按钮不可用并逐条显示原因（分值合计不符、依赖成环/不存在、分值为 0 或负、题型不支持、与原文冲突等）。
- 同一试卷同一题同一时刻只有一条生效规则；历史判分保留旧版本引用，不回溯改历史。
- 答案键版本与规则版本相互独立：改答案键不递增规则版本，改规则不递增答案键版本。

## 5. 多选部分给分

- 多选题的模板骨架可以携带部分给分档位（正确选项数、各档命中数与分值），具体数值由模板数据给出，不写死在代码里。
- 档位在确认时随规则版本冻结；同一份试卷的同一题沿用同一套档位。
- 若模板没有档位而你需要部分给分，请在规则原文里写清楚（例如「漏选得一半分，错选不得分」），整理后逐档核对再确认。

## 6. 分步给分与依赖

- 评分项之间可以设置依赖（前置步骤必须先满足）；依赖成环或指向不存在的评分项会被校验拦截。
- 「必须满足」的评分项不满足时的处理，由计分方式决定（累加/全对才给分/分步给分），确认前请核对。
- 没有具体答案、只有评分标准的题，必须有已确认规则才允许判分；否则整卷就绪检查失败。

## 7. 常见问题

**模型整理后能直接用吗？** 不能。整理结果只是草稿，必须由你确认；确认前不参与任何判分。

**模板分值和实际试卷不一样怎么办？** 套用后逐个题调整分值；模板只是骨架，不保证与你的试卷一致。

**规则改错了能回到旧版本吗？** 历史判分保留旧版本引用；你可以基于旧版本新建草稿并确认，但不会「撤销已生效版本」，而是产生新版本。

**为什么确认按钮是灰的？** 看校验问题列表；错误级问题必须全部处理后才能确认。
