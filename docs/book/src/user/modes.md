# 标准与快速模式

> 状态：M10 文档初稿（计划中）。模式开关、抽检队列与弹窗随 M7/M8/M9 提供；阈值与比例以 `CONFIG.md` 为准。

## 1. 两种模式的区别

| 维度 | 标准模式（默认） | 快速模式 |
|---|---|---|
| 定位 | 正式成绩，高门槛、可追溯 | 时间紧时的可用结果，低门槛、抽检 |
| 自动接受阈值（仅规则 / 规则升级 / 直接模型 / 按规则逐项） | 0.85 / 0.90 / 0.85 / 0.80 | 0.80 / 0.80 / 0.75 / 0.70 |
| 未校准模型 | 禁止自动放行 | 允许但需 ≥0.90，且结果标记抽检 |
| 抽检 | 不做强制抽检 | 按比例 0.20、低置信度权重 0.70 加权随机 |
| 结果标注 | 记录为「标准」 | 记录为「快速」，导出带标注 |
| 统计 | 标准样本单独统计 | 快速样本单独统计，不与标准混合 |

核心原则：**两种模式的结果不能混算、不能互相冒充**。每条判分记录都带模式，即使之后切换模式，历史记录也不会改变；统计与导出按记录自身的模式分组。

## 2. 抽检是怎么抽的

快速模式会自动接受更多结果，因此按比例送抽检：

1. 候选 = 快速模式中已自动接受的题目。
2. 「低置信度」= 置信度低于当前模式阈值 + 0.10 的题目；低置信度权重 0.70，其余题目权重 0.30。
3. 抽取数量 = 候选数 × 抽检比例（默认 0.20，向上取整，至少 1 题）。
4. 按权重**无放回随机**抽样；随机种子与抽检结果写入审计与判分记录，保证可复查、可复现。
5. 抽检通过：只记录「抽检通过」，不改分。
6. 抽检不通过：弹出窗口询问是否重跑（见下节）。

抽检比例与低置信度权重都可以在设置中调整；调整后只影响之后的新任务。

## 3. 抽检不通过怎么办

弹窗会展示「原判定」与「抽检判定」的差异，提供两个范围：

| 选项 | 行为 |
|---|---|
| 仅本题（默认） | 以标准模式重判该题，生成新修订；原快速记录保留可审计 |
| 整卷 | 生成整卷重判任务；同一份提交的其他题不被单题重跑覆盖 |
| 取消 | 保持待复核，不自动重跑；不会静默通过或静默重跑 |

重跑不直接改分：重跑产生新的判分修订，统计与导出以最新修订重算。整卷重跑不会自动刷新已导出的报表，需要重新导出。

## 4. 快速结果转标准复核

- 在抽检队列或提交详情中可「一键转标准复核」：以标准模式对同一题（或整份提交）重新判分。
- 原快速记录保留并标注「已转标准」，不删除；统计随最新修订归入标准模式。
- 转换后如果判分仍无法自动接受，会进入标准待复核队列，由你人工确认或改分。

## 5. 什么时候用哪种

| 场景 | 建议 |
|---|---|
| 期中/期末正式成绩、需要归档与申诉依据 | 标准模式；宁可多花时间复核 |
| 课堂小测、随堂练习、只需要大致分布 | 快速模式；接受抽检与后续抽查 |
| 试卷/规则刚建立，想先看效果 | 快速模式试跑，确认无误后再用标准模式重跑 |
| 已用快速模式出了成绩又要正式版 | 对整份提交「转标准复核」或重新以标准模式判分，不要直接拿快速结果当正式成绩 |

## 6. 模式切换规则

- 默认模式取设置（默认标准模式）。
- 切换需要二次确认；有运行中任务时**禁止切换**（按钮禁用并说明原因），避免同一批结果口径混杂。
- 切换只影响之后的新任务，不追溯改历史判分。
- 快速模式下每页顶部有常驻提示条，导出文件名与报表也会标注「快速」（可配置关闭文件名/表头标注，但数据列与元信息始终保留模式）。

## 7. 导出时如何区分

- 文件名含模式 token（`标准`/`快速`/`全部`）。
- 报表行内带模式列；题目统计、班级汇总、分布图都按模式分组。
- 「全部」只用于对照查看，不产生「混合总分」。
- 快速模式另有「快速抽检」工作表，记录抽检状态与是否转标准。

## 8. 常见问题

**快速模式的分数能直接上报吗？** 不建议。快速模式的结果带快速标记、有抽检但非全量复核；正式用途请转标准复核或重跑。

**抽检比例可以设成 1.0 吗？** 可以（范围 0.05–1.00），但那就接近全量送抽检，失去快速模式的意义。

**为什么两套统计不能合并？** 阈值与人工介入程度不同，合并会得到没有意义的「平均分」；规范要求模式可分辨（S11）。

**切换模式后旧成绩会变吗？** 不会。历史记录保留原模式与分数，只有新任务使用新模式。
