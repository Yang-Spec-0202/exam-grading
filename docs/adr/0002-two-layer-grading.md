# ADR-0002：两层判分（L1 路由 + L2 判定）

> 状态：已接受 · 2026-11-02 · 决策者：项目（单机匿名教师）· 相关规范：`SPEC.md` §1.1/§1.2/§3 S2/S5/S8、`SPEC-grade.md` §3–§5/§8、`SPEC-domain.md` §8
> 说明：本页记录「为什么这样设计」，「必须/禁止什么」以规范为准，不复制条文。

## 1. 背景

- 判分依据只能是教师提供的参考答案与评分标准；规范禁止「把题丢给模型自由判断」，也禁止缺答案时让模型自造答案（`SPEC.md` §10 Never）。
- 题型差异大：选择/判断/填空/数值可确定性判定；解答题需要语义等价与分步给分；部分题只有评分标准（无具体答案），只能按评分项判。
- 成本与可解释性：目标机 M4/16GB 上 4B 判定模型单题耗时与内存都有限（`docs/dev/research/models.md`、`inference-serving.md`），模型调用不可无限使用；教师需要能看懂「为什么给这个分」。
- 复现要求：任一历史判分可用版本与哈希重放出同一结果（S8），因此每条结果必须带路由轨迹与判定证据。

## 2. 决策

- **L1 是纯函数路由表**：输入只有题型、答案键变体、规则是否存在且已确认、识别置信度、后端可用性、模式；输出「仅规则 / 规则优先再升级模型 / 直接模型 / 按评分标准 / 仅人工」五类路由；默认不调用任何模型。
- **L2 按路由执行**：规则路由走学科比较器链（首个确定结论终止，全部无法判定才升级），模型路由只做「与参考答案/评分标准是否对得上」的受限判定，输出经严格 Schema 校验。
- **规则优先**：能规则确定的绝不调模型；模型的产出永远不是最终裁决，冲突时按仲裁表处理（规则与模型不一致默认升级人工）。
- **缺失即人工**：答案键为「明确省略」或「缺失」且无有效规则时，L1 直接给「仅人工」，不得让 L2 生成答案。
- **门禁与证据**：置信度低于当前模式阈值、无证据、冲突未解决、模型未校准（标准模式）时一律进复核；每条判分记录至少一条证据。
- 路由轨迹（命中的规则编号、输入哈希、判定时间）随判分记录持久化，作为复现入口。

## 3. 后果

- 正面：成本可控（多数题不触模型）；判定可解释、可表驱动测试（`SPEC-grade.md` §7 要求每个分支有正例与边界例）；规则覆盖不足时退化为人工而不是错分。
- 负面：需要维护比较器链、路由表与冲突仲裁表；规则覆盖不足的题型人工率会上升；L2 模型能力上限受 4B 量化模型限制（主观题准确率目标 S3 只有 85% 完全一致）。
- 后续动作：新增题型/比较器时同步 L1 路由表与夹具；模型或提示词升级必须写新引擎指纹，不得复用旧记录；ECE 校准回流依赖复核数据（`SPEC-grade.md` §6）。

## 4. 替代方案

| 方案 | 优点 | 缺点/风险 | 结论 |
|---|---|---|---|
| A：单层大模型直接判分 | 实现简单、题型无关 | 不可解释、幻觉不可控、成本高、离线弱、违反「以参考答案为准」 | 放弃 |
| B：纯规则无模型 | 零幻觉、极快、可复现 | 开放答案/证明/多解无法判定，人工率过高 | 放弃 |
| C：规则 + 模型投票（双判取一致） | 降低单点误判 | 模型成本翻倍；冲突更多；离线性能不可接受 | 不作为默认；冲突仲裁表保留「规则优先 + 记冲突」的折中 |
| D：两层（规则优先，模型只做未决升级） | 成本、可解释性、离线性平衡 | 需要维护两套契约 | **采用** |
