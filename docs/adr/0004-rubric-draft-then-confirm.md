# ADR-0004：评分规则结构化——模型只产草稿、教师确认后生效

> 状态：已接受 · 2026-11-02 · 决策者：项目（单机匿名教师）· 相关规范：`SPEC.md` §1.5/§3 S12/§13.1、`SPEC-rubric.md` §2.2/§2.5/§3.2/§3.4、`SPEC-domain.md` §5
> 说明：本 ADR 解释「为什么规则不能让模型直接生效」；具体校验项与状态机以规范为准。

## 1. 背景

- 教师的评分标准是自然语言（「写出判别式给 2 分，代入正确再给 1 分」），录入必须尽量省力；规范同时要求「模型不得在无参考答案时凭空生成标准答案」，规则同理不能让模型自定口径。
- 规则是判分依据，一旦生效会改变所有学生的分数；错误规则比错误识别更难被发现，且会破坏历史复现。
- 教师已明确：规则可手写、可套全国卷模板、可由模型整理，但**必须教师确认**才生效。
- 全国卷模板是公开试卷的快照数据，含 active（现行）与 retired（历史快照）两类，分值/结构由模板数据定义，不在规范里写死。

## 2. 决策

- **三条来源、一条出口**：手写原文直译、模型整理、套用模板，全部产出 `RubricDraft` 草稿；草稿经静态校验后由教师确认，才生成生效的 `Rubric` 新版本。
- **模型只做格式整理**：拆评分项、补结构化字段、统一分值表达为千分之一分整数；不得新增原文没有的判据、不得修改分值语义、不得生成/修改答案键、不得判断学生答案、不得决定生效；整理输入不含任何学生作答数据。
- **确认恒开**：`rubric.require_confirmation` 为不可配置不变量；界面不提供「跳过确认」入口。
- **校验门禁**：分值合计不符、依赖成环/不存在、分值为 0 或负、题型不支持、与原文语义冲突 → 错误级问题，阻止进入「待确认」与确认按钮。
- **版本化**：生效规则版本与试卷 `rubric_version` 对齐；历史判分保留旧版本引用，不回溯改历史；答案键版本与规则版本相互独立。
- **模板生命周期**：全国卷模板包（新课标Ⅰ卷、新课标Ⅱ卷、全国甲卷、全国乙卷）随包只读；每套带 `active`/`retired` 标注，retired 必须带停止命制年份（甲卷 2026、乙卷 2024），只读且不得删除，仅用于历史试卷与历史判分复现；状态流转只允许 active→retired，且需升版本并写审计。
- **多选部分给分**：模板骨架可携带部分给分档位引用（正确选项数、各档命中数与分值），具体数值由模板数据给出，不写进代码；确认后随规则版本冻结。

## 3. 后果

- 正面：规则可解释、可追溯、可复现；模型无法单方面改变判分口径；模板降低重复录入成本；历史试卷可用 retired 模板复现。
- 负面：教师必须逐题确认，录入时间增加；模型整理可能多次往返；模板数据需要维护（已声明不承诺持续维护、以快照稳定优先）。
- 后续动作：确认人固定 `local-teacher` 并写审计（无登录）；整理失败或 Schema 不合法时不得生成可确认草稿；模板更新属 Ask first。

## 4. 替代方案

| 方案 | 优点 | 缺点/风险 | 结论 |
|---|---|---|---|
| A：模型整理结果直接生效 | 教师最省力 | 违反「以教师标准为准」；错误规则不可见地污染全部成绩；不可复现 | 放弃 |
| B：只允许教师手工逐项结构化 | 最可控 | 录入成本过高，实际会退化为「随便填」 | 放弃 |
| C：模型生效 + 事后抽样审计 | 省力且有检查 | 出错时成绩已产生；审计不能替代事前确认 | 放弃 |
| D：模型/模板只产草稿，教师确认后生效（采用） | 成本与可控平衡 | 每份规则多一步确认 | **采用** |
