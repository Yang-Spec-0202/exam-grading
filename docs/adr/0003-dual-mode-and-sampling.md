# ADR-0003：标准/快速双模式与加权抽检

> 状态：已接受 · 2026-11-02 · 决策者：项目（单机匿名教师）· 相关规范：`SPEC.md` §1.7/§3 S11/§13.1、`SPEC-grade.md` §3/§7、`SPEC-review.md` §3.2、`SPEC-report.md` §3.3、`CONFIG.md` §6
> 说明：本 ADR 解释模式与抽检的取舍；阈值与比例默认值以 `CONFIG.md` 为准。

## 1. 背景

- 教师既要「严谨可追溯」的正式成绩，也要在时间紧时快速得到可用结果。
- 单一阈值只有一种取舍：门槛高则人工量过大，门槛低则误判进成绩且无法区分。
- 用户明确要求两种模式、快速模式需要抽检、抽检不通过可重跑；并要求模式在记录、导出、统计中可分辨（不可混淆）。
- 抽检若做「均匀随机」，低置信度题目容易被漏检；若只抽最低置信度，又失去随机覆盖的统计意义。

## 2. 决策

- **模式写入每条记录**：`GradeRecord.mode` 取「标准/快速」，判分时固定，历史记录不因之后切换而改变。
- **两套阈值**：标准模式 0.85/0.90/0.85/0.80（仅规则/规则升级/直接模型/按规则逐项），快速模式 0.80/0.80/0.75/0.70；未校准模型标准模式禁止自动放行，快速模式须 ≥0.90 且标记抽检。
- **加权随机抽检**：抽检比例默认 0.20（可调），低置信度权重 0.70；「低置信度」定义为低于当前模式阈值 +0.10 的题目；抽取数量 = 候选数 × 比例（向上取整，至少 1 题）；无放回加权随机；种子与结果写入审计与判分记录，保证可复现。
- **抽检队列只读**：抽检记录只能「抽检通过」或「抽检不通过（发起重跑）」或「转标准复核」，不允许直接改分；避免快速结果被无声改写。
- **抽检不通过先询问**：`app` 弹窗显示原判定与抽检差异，默认范围「仅本题」，可选「整卷」；取消则保持待复核、不自动重跑。
- **转标准 = 重判**：以标准模式对同一题重新判分生成新修订，原快速记录保留可审计；统计随最新修订归入标准模式。
- **不可混合**：标准与快速分别统计、分别标注；任务运行中禁止切换模式。

## 3. 后果

- 正面：同一套流程覆盖「正式」与「草稿」两种使用强度；低置信度题目被优先抽到但仍保留随机性；快速结果不会被误当正式成绩（模式列 + 文件名 + 表头标注）。
- 负面：两套阈值与两套统计增加维护成本；快速模式的结果质量依赖抽检覆盖，抽检比例降低会提高漏检风险；教师需要理解「快速结果不是最终成绩」。
- 后续动作：抽检命中率与不通过率进告警（`SPEC-grade.md` §9）；比例/权重调整属 Ask first；若后续发现某题型在快速模式误判偏高，优先调阈值而非改抽检权重。

## 4. 替代方案

| 方案 | 优点 | 缺点/风险 | 结论 |
|---|---|---|---|
| A：只保留标准模式，教师手动调阈值 | 实现简单、统计单一 | 无法区分「正式」与「快速」；历史成绩口径不可辨；用户明确要求双模式 | 放弃 |
| B：双模式但抽检均匀随机 | 抽样无偏、实现简单 | 低置信度题目漏检率高，抽检意义弱 | 放弃（权重 0.70 保留随机性同时偏向风险题） |
| C：双模式 + 全量人工复核快速结果 | 质量最高 | 失去「快速」意义，人工量回到标准模式水平 | 放弃 |
| D：双模式 + 加权抽检 + 只读抽检队列 + 不通过询问重跑 | 质量、成本、可审计平衡 | 需要两套阈值/统计与一次弹窗交互 | **采用** |
