# ADR-0006：任务级云端授权（默认离线）

> 状态：已接受 · 2026-11-02 · 决策者：项目（单机匿名教师）· 相关规范：`SPEC.md` A6/S10、`SPEC-inference.md` §2.3/§5、`SPEC-app.md` §2 consent 页、`CONFIG.md` §10
> 说明：本 ADR 解释「为什么是任务级授权，而不是每次弹窗或永久许可」。

## 1. 背景

- 学生作业含姓名、学号、手写答案，属于个人信息；规范默认离线，任何外发都必须可控、可审计、可撤销。
- 云端只是兜底能力（本地模型不可用、疑难主观题），不是常态路径；用户要求「每次任务鉴权」，而不是每次调用都弹窗。
- 需要能回答：这次外发了哪些内容、花了多少钱、最终有没有越界——因此授权必须与具体任务、范围、预算绑定并写入审计。

## 2. 决策

- **默认关闭**：`privacy.cloud_enabled` 默认关；总开关关闭时申请授权即被拒绝，不排队、不预热。
- **授权绑定任务**：授权对象含 `task_id`、允许后端（当前仅 `openai_compat`）、范围指纹 `scope_hash`（哪些资产/文本可外发）、费用上限 `budget_micros`、状态与起止时间；一次授权只覆盖一个任务或一个显式任务集合。
- **有效期 = 任务生命周期**：任务开始登记，任务到终态（成功/失败/取消）即结束；续跑必须重新授权；不设跨任务时间窗，不支持整批授权覆盖多任务。
- **每次调用前校验**：任务、后端、范围、预算、状态五项全部通过才发出请求；`consent_id` 写入模型调用记录；范围外内容硬拒绝并审计，不裁剪后「尽量发送」。
- **授权页交互**：新建一次授权 ≤4 次交互、≤60 秒；撤销立即生效；无有效授权时任务以「策略拦截」显式失败并引导到授权页，不悄悄降级为本地。
- **原图默认不外发**：`privacy.send_original_image` 默认关，只发裁剪/脱敏内容；云端调用记录模型版本、提示词哈希、输入哈希、任务与授权 id。
- **密钥不入库**：API Key 只从系统密钥链读取，不写数据库、不写日志、不写仓库。

## 3. 后果

- 正面：默认零外联；每次外发可解释、可撤销、有预算上限；断网可完成全流程（S10）；批量任务只需一次授权确认，不打扰教师。
- 负面：任务中断续跑需要重新授权；预算需要教师预估；授权页需要维护授权历史与状态。
- 后续动作：若未来支持本地后端之外的更多云端厂商，仍沿用同一授权结构；成本估算展示列为开放问题；授权状态变化必须事件化并实时反映到界面横幅。

## 4. 替代方案

| 方案 | 优点 | 缺点/风险 | 结论 |
|---|---|---|---|
| A：每次模型调用弹窗授权 | 控制最细 | 打扰极强，批量任务不可用；用户明确否决 | 放弃 |
| B：整批/永久授权（一次授权长期有效） | 最省事 | 无法随任务失效；范围与预算难约束；泄露面大 | 放弃 |
| C：云端默认开启、按需关闭 | 体验顺滑 | 违反默认离线与隐私要求（S10） | 放弃 |
| D：任务级授权 + 范围/预算 + 任务终态失效（采用） | 一次确认、可控可审计 | 续跑需重新授权 | **采用** |
