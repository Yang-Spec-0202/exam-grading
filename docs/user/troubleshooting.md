# 常见故障

> 状态：M10 文档初稿（计划中）。错误文案与恢复入口以发布版本为准；本节给出排查顺序与系统设计的处置方式。

## 1. 先看这两个地方

1. **顶栏横幅**：模型未就绪、云端授权失效、后端熔断等常驻问题会显示在这里。
2. **日志与诊断页（`Cmd+L`）**：按级别、模块、追踪 id、任务 id、时间过滤，可复制诊断 id、导出诊断包、打开日志目录。每条错误都应有一个可点击的下一步动作。

## 2. 模型与推理

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 首次判分一直等待 | 首次加载模型（OCR 约 1.8GB BF16 + 4B 判定模型）较慢 | 等就绪提示消失；不要在加载中强行取消整个批次 |
| 「本地模型未就绪，判分已暂停」 | 模型文件缺失、哈希不符、sidecar 启动失败或端口被占用 | 打开诊断页看具体错误；用 `scripts/model/` 校验/重启；仍失败则换后端或转人工 |
| 模型被拒绝加载 | 权重哈希不符或许可门禁未通过 | 重新下载并校验；不要绕过许可门禁 |
| 判分突然变慢/超时 | 单页识别或单题判定超时、内存压力 | 看进度页失败项；减少并发；超时项会进人工，不会返回半成品 |
| 云端调用被拦截 | 未授权、授权过期/撤销、预算用尽、范围外内容 | 到授权页查看状态并重新授权；系统不会悄悄改用本地 |
| 日志索引重建中 | 索引不可用 | 诊断页退化为字段过滤，不影响查看；等重建完成 |

## 3. OCR 与识别

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 密集小字漏识 | OCR 输入被下采样到约 1MP | 把页面按版面分块（分栏/分区域）；**提高 PDF DPI 无效** |
| 公式识别失败 | LaTeX 不合法或字符集不支持 | 该题按「不可判定」转人工；不要手工改判分规则迁就识别 |
| 透明底页面识别空白 | PDF 默认透明背景 | 导入时会合成白底；若是自备图片请先转白底 |
| 加密 PDF 打不开 | 不支持加密/口令 PDF | 先解密另存为标准 PDF 再导入 |
| HEIC 导入失败 | 系统解码器不可用 | 转成 JPG/PNG 再导入 |
| 手写体识别差 | 模型能力边界 | 走人工复核或修文本重判；不要期待「识别不出来就自动算对」 |

## 4. 导入

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 页面被拒收 | 模糊/欠曝/过曝/倾斜/分辨率不足/眩光/死黑 | 按原因码重拍；补拍页可追加到同一提交指定页号 |
| 一批导入被拒绝 | 单批文件数超过上限（默认 2000） | 拆批导入 |
| 「疑似重复提交」 | 与既有提交页面重合 ≥80% | 确认是补交还是重复；重复则保留一份 |
| 文件名未匹配 | 文件名不符合命名规范（相机名、含空格、全角等） | 在未决列表选择学生；或改名后重新导入（应用不改你的文件） |
| 只剩部分页 | PDF 损坏或页序异常 | 检查原文件；损坏按文件级失败，不产生半页 |

## 5. 规则与试卷

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 确认按钮不可用 | 静态校验有错误级问题 | 按问题列表逐条修改：分值合计、依赖成环、分值为 0/负、题型不支持 |
| 判分前提示「试卷未就绪」 | 某题既无具体答案、又无已确认规则、也未标记「仅人工」 | 补答案键或规则，或把该题标为仅人工 |
| 模板套用后分值不对 | 模板只是骨架，分值与你的试卷不一定一致 | 逐题调整后确认；不要直接套用不核对 |
| 历史试卷打不开/复现不了 | 使用了 retired 模板或旧规则版本 | 历史记录保留旧版本引用；检查模板版本是否一致 |

## 6. 复核

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 快速抽检项不能改分 | 抽检队列只读 | 用「抽检不通过（发起重跑）」或「转标准复核」 |
| 改分被拒 | 分数越界/粒度不符/原因码未选/修订号过期 | 按提示修正；多窗口同时操作时刷新后重试 |
| 撤销不可用 | 没有可撤销动作或已到 50 步上限 | 继续人工处理；撤销是追加反向动作，不影响历史 |
| 重判一直转圈 | 后端不可用或该题被锁定 | 等重判结束或取消后重试；不要重复提交并发命令 |

## 7. 导出与文件

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 导出失败无文件 | 磁盘空间不足、目标被占用、越界/守恒校验失败 | 清理磁盘或换目录；越界数据必须修正，系统不会截断 |
| 提示已存在同名文件 | 默认不覆盖 | 选择覆盖（二次确认）或改目录 |
| CSV 乱码 | 被其他工具另存过 | 重新导出；正常导出带 BOM |
| 脱敏文件里还有姓名 | 只做了内容脱敏但试卷名/备注含姓名 | 改用中性试卷名；检查备注与答案原文 |

## 8. 启动与数据

| 症状 | 可能原因 | 处理 |
|---|---|---|
| 提示已有实例 | 单实例锁 | 找到已运行窗口或结束旧进程；不要同时开两个 |
| 启动进入诊断界面 | 配置损坏、数据库损坏或迁移失败 | 按提示修复/恢复上一版/从备份恢复；选择会写审计 |
| 磁盘满 | 原图永久保留、无自动清理 | 系统不提供删除原图；请扩容或迁移工作区；导入按钮会禁用并说明 |
| 备份恢复后数据对不上 | 恢复的是旧备份 | 恢复会校验资产哈希与记录计数；以恢复时间为准 |

## 9. 诊断包包含什么

- 日志（脱敏后）、配置快照、schema/迁移清单、任务与失败摘要、版本与平台信息。
- **不包含**：原图、学生姓名/完整学号明文、API Key。
- 导出失败会明确报错并给出目标路径，不产生半成品文件；诊断包可以发给开发者排查，但仍建议自行检查是否含敏感信息。

## 10. 还是解决不了

1. 复制诊断 id（映射到日志与任务），记录你刚才的操作步骤。
2. 导出诊断包。
3. 附上版本信息（应用版本、系统版本、模型 id/版本）提交问题；不要发送学生原图。
