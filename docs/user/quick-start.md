# 快速开始

> 状态：M10 文档初稿（计划中）。本页描述目标路径；桌面外壳与业务模块尚在实现，实际界面与按钮以发布版本为准。未标注「已可用」的步骤均属计划。

## 0. 开始前准备

| 项 | 要求 | 说明 |
|---|---|---|
| 机器 | Apple Silicon / 16GB 内存 | 规范目标机（`SPEC.md` A5） |
| 运行方式 | 开发机直接运行（`cargo run -p eg-app`） | 不做 .app/DMG 分发（A7） |
| 本地模型 | OCR 0.9B 与 4B 级判定模型，放在应用数据目录 | 下载与校验用 `scripts/model/` 脚本，见 `../dev/research/models.md` |
| 试卷材料 | 参考答案、题目结构（可选评分规则） | 答案键缺失的题只能人工判 |
| 学生作业 | 按「学生名/学号」命名的图片或 PDF | 文件名是唯一身份来源 |

## 1. 首次启动（计划中，M9）

1. 启动应用：首次会创建本地工作区（配置、SQLite 数据库、内容寻址资产库、日志目录）。
2. 首页会显示待复核数、最近试卷、模式徽标、本地后端与磁盘状态。启动阶段有预算（首帧 P50 ≤1.0s），模型探测在后台进行，不阻塞首帧。
3. **首次加载模型较慢**：OCR 官方 GGUF 为 BF16（约 1.8GB 双文件），加上 4B 判定模型，首次加载可能需要数十秒到数分钟，取决于磁盘与内存。顶栏会常驻提示「本地模型未就绪，判分已暂停」，等就绪后再开始判分即可，不需要重装。
4. 如果模型文件缺失或哈希不符，应用会拒绝加载并给出缺失文件清单（`SPEC-inference.md` §5），按提示用脚本补齐。

> 单实例：同一工作区只允许一个应用实例。重复启动会提示已有实例的进程号与启动时间并退出。

## 2. 新建班级与名单（计划中）

1. 新建班级（名称、学期）。
2. 导入名单 CSV：至少包含「学号」「姓名」两列；也可手工新增个别学生。名单是身份匹配的唯一依据，导入后请检查重名、空学号、重复学号。
3. 名单之外的学生不会自动建档：文件名未命中的作业默认进「未决」，需要你补名单或标为无效提交。

## 3. 建立试卷与答案键（计划中）

1. 新建试卷：填写标题、题号（卷面顺序）、题型、满分；系统校验各题满分之和等于整卷总分。
2. 逐题录入答案键，四种状态：
   - 具体答案（可含多解/等价写法、容差）；
   - 仅评分标准（无具体答案，按评分项判）；
   - 明确「略」（等于没有答案，只能人工）；
   - 缺失（未提供，只能人工）。
3. 可选：标注**模板区域**（每页每题的作答范围）。有模板时区域对齐优先走模板，比自动检测稳定；模板版本必须与答案键版本一致，否则自动禁用模板路径。
4. 参考答案也可从 DOCX/PDF/图片导入后识别、再由你确认（参考答案的识别结果同样要人工确认，不能直接使用）。

## 4. 录入评分规则（计划中）

- 两条路径：直接套用全国卷模板包（新课标Ⅰ卷、新课标Ⅱ卷为现行；全国甲卷、全国乙卷为历史快照，只读），或手写自然语言规则由模型整理。
- 模型整理只会产出**草稿**；草稿经静态校验后必须由你确认才生效（恒开，不可关闭）。校验有错误时确认按钮不可用。
- 没有规则、没有具体答案的题，会在开始时被标记为「仅人工」，不会让模型自造答案。

## 5. 导入学生作业（计划中）

1. 选择文件或文件夹；系统会提示「建议按 学生名/学号 命名」（`import.remind_naming` 默认开）。
2. 支持 JPG/JPEG、PNG、HEIC/HEIF、TIFF、PDF；加密或损坏的 PDF 会整份失败并明确报错（不产生半页）。
3. 导入前会做质量门控：模糊、过曝/欠曝、倾斜、分辨率不足的页会被拒收并给出原因；默认「页级拒收、批次继续」，你可以补拍后追加到同一提交的指定页号。
4. 导入页会预览「文件名 → 学生」的匹配结果；未匹配的文件加入未决列表，等你在名单里选择。
5. 重复导入会被处理：同字节资产只存一份；页面与既有提交重合 ≥80% 时提示「疑似重复提交」，默认询问而不是自动建档。

## 6. 开始判分（计划中）

1. 选择模式：**标准模式**（默认，高门槛、可追溯）或**快速模式**（低门槛、按 20% 比例抽检、结果带快速标记）。
2. 任务执行期间**不能切换模式**；切换需要二次确认，且只影响之后的新任务。
3. 进度页显示各阶段、耗时、失败项与重试入口；可取消（已写入的资产保留，不产生半页）。
4. 判分结果分三路：自动接受、待复核、失败/不可判定。低置信度不会绕过门禁进入最终成绩。

## 7. 复核（计划中）

1. 标准模式：进入「复核」页，队列按风险排序（冲突 > 不可判定 > 置信度不足 > 证据缺失 > 未校准 > 后端不可用 > 分数非法）。
2. 快速模式：只处理「抽检」队列；抽检项**只读**，只能「抽检通过」「抽检不通过（发起重跑）」或「转标准复核」。
3. 常用键盘操作：`J`/`K` 下一题/上一题、`Enter` 确认、`E` 改分、`Space` 证据面板、`X` 排除、`Cmd+Z` 撤销。
4. 每次改分都要选原因；改分产生新修订，不覆盖历史。

## 8. 导出（计划中）

1. 报表页选择模式（标准/快速/全部）、格式（XLSX/CSV/HTML）与是否脱敏。
2. 文件名规则：整卷 `试卷名_模式_时间戳`；学生成绩单 `学生名_试卷名_模式_时间戳`；脱敏追加 `_脱敏`。
3. 导出是原子的：要么完整生成，要么不产生文件；已存在的同名文件默认不覆盖。
4. 导出后如再改分，需要重新导出（报表按最新修订重算）。

## 最短路径检查单

- [ ] 名单导入且无重名/空学号
- [ ] 试卷总分校验通过
- [ ] 每道题有具体答案、已确认规则，或明确标记「仅人工」
- [ ] 所有作业按学生名/学号命名
- [ ] 无质量拒收页或已补拍
- [ ] 无未决身份项
- [ ] 导出前确认没有未复核项混入正式成绩
