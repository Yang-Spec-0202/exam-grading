# 隐私与数据

> 状态：M10 文档初稿（计划中）。隐私相关行为由 `SPEC.md` A6/A8、`SPEC-inference.md`、`SPEC-platform.md` 与 `CONFIG.md` §10 约束；界面入口随实现提供。

## 1. 默认全部本地处理

- 应用是单机桌面程序：识别、对齐、判分、复核、导出都在本机完成。
- **默认离线**：不联网也可以跑完整流程（断网完成导入到导出是验收标准 S10）。
- 没有登录、没有账号、没有云端同步；所有审计记录的操作者固定为 `local-teacher`。

## 2. 原图与数据保留

| 数据 | 位置 | 保留策略 |
|---|---|---|
| 作业原图/扫描件 | 本地工作区的内容寻址资产库（按内容哈希只读保存） | **永久保留，不自动清理**；应用不提供删除原图的功能 |
| 派生图（方向校正、透视矫正、二值、缩略图） | 资产库 | 可由原图 + 流水线版本重建 |
| 数据库（名单、试卷、判分、审计） | 本地 SQLite（WAL） | 随工作区保留；迁移只追加 |
| 日志 | 本地日志目录 | 默认保留 30 天（可配 7–365），按天轮转 |
| 隐藏/临时目录 | 系统临时目录 | 不用于长期保存；导出中途失败会清理临时文件 |

注意：

- 因为不做自动清理，「导完就删」不存在；需要释放空间请扩容、迁移工作区，或在操作系统层面自行处理（应用不代为删除）。
- 工作区可以整体备份/迁移；数据库与资产目录要一起迁移，否则判分无法复现。
- 屏幕共享、远程协助时注意：界面会显示原图与识别文本。

## 3. 云端推理：默认关闭、按任务授权

- 云端总开关默认**关闭**；即使打开，也必须为具体任务单独授权（`privacy.per_task_consent` 恒开，不可关闭）。
- 一次授权只覆盖一个任务：包含允许的后端、可外发内容范围、费用上限与有效期；任务结束（成功/失败/取消）即失效，续跑要重新授权。
- 授权范围内才发请求；范围外内容硬拒绝并写审计，不会「裁剪后尽量发送」。
- 原图默认不外发（`privacy.send_original_image` 默认关），只发裁剪/脱敏内容。
- 无有效授权时任务以「策略拦截」显式失败并提示去授权页，不会悄悄改用本地、也不会悄悄外发。
- 云端调用记录模型版本、提示词哈希、输入哈希、任务 id 与授权 id，可审计。

## 4. 日志与审计脱敏

- 日志默认脱敏：姓名打码、学号只留后 4 位、路径不落原文（只记哈希前缀）；关闭脱敏需要二次确认。
- 判分与复核的审计记录只追加、哈希链校验；审计不写学生姓名明文与 API Key。
- 诊断包包含日志、配置、schema、任务摘要与版本信息；不包含原图、学生姓名/完整学号明文、密钥。
- 应用内日志查看器支持按模块/追踪 id 检索；日志与诊断包分享前请自行复核内容。

## 5. 密钥与模型

- 云端 API Key 只从系统密钥链读取，不写数据库、不写日志、不写仓库；界面上不回显明文。
- 大模型权重不随仓库分发，存放在应用数据目录，按各自模型许可使用；代码许可与模型许可分开。
- 本地推理服务只监听本机回环地址，端口由应用分配或固定（设置可查）。

## 6. 导出与分享

- 对外分享成绩时建议使用**脱敏导出**：姓名/学号替换为掩码、不导出答案原文与原始图片路径。
- 脱敏是去标识化，不是匿名化：持有名单的人仍可能重识别；发给谁、发到什么范围请自行判断。
- HTML 报告是单文件、无外部引用，不会在打开时联网。

## 7. 许可与合规

- 本项目整体以 **GPL-3.0-only** 发布（源码公开、不做二进制分发）；完整许可文本见仓库根目录 `LICENSE`。
- GUI 使用 Slint 1.18.1，按其 GPL-3.0-only 分支使用：不启用 Royalty-free 归属方案、不购买商业许可。
- 第三方依赖许可由 `deny.toml` 白名单 + `cargo deny check` 强制（未列入白名单即构建失败，fail-closed）。
- 模型权重遵循各自模型卡许可；使用前请核对模型许可与用途限制。

## 8. 你应该做的隐私操作

1. 多教师共用一台电脑时：为每人使用独立的工作区目录与系统账户；应用本身不区分用户。
2. 借用/送修电脑前：备份并移走整个工作区（在原图永久保留的前提下，这等同于数据迁移）。
3. 分享报表前：优先脱敏导出；确认试卷名/备注不含个人信息。
4. 提交问题前：只提供诊断包与复现步骤，不要附学生原图。
5. 开启云端前：确认学校/家长对数据外发的许可要求；用最小范围授权并设置预算上限。
