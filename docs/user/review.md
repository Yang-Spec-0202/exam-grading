# 复核工作台

> 状态：M10 文档初稿（计划中）。工作台随 M8/M9 提供；快捷键与队列规则见 `SPEC-app.md` §2.1、`SPEC-review.md`。

## 1. 两个队列

| 队列 | 来源 | 你能做什么 |
|---|---|---|
| 标准复核队列 | 标准模式中待复核的题（低置信度、冲突、不可判定、证据缺失、未校准、后端不可用、分数非法） | 接受、改分、修文本重判、排除、批注、批量确认 |
| 快速抽检队列 | 快速模式中被抽检且已自动接受的题 | **只读**：抽检通过、抽检不通过（发起重跑）、转标准复核；不能直接改分 |

标准队列按风险排序：冲突 > 不可判定 > 置信度不足 > 证据缺失 > 未校准 > 后端不可用 > 分数非法；同级按置信度升序、分值、题序、学号排序，顺序稳定可复现。

快速抽检队列按抽检清单顺序展示，并标出「是否已转标准」。

## 2. 界面三栏与证据联动

- 左：队列与过滤（模式、状态、原因、学生/题号、是否只看未复核）。
- 中：原图、裁片与题目区域高亮；支持缩放、旋转、整页/裁剪切换；多页题可切页。
- 右：参考答案/评分标准摘要、识别文本与置信度、判定与证据、分数输入、原因与备注。
- 点击评分项或证据会定位到对应裁片区域；没有坐标的证据显示「无定位」。
- 图片按需加载，不阻塞界面。

## 3. 键盘操作（默认，可在设置调整）

| 键 | 动作 |
|---|---|
| `J` / `K` | 下一题 / 上一题 |
| `Enter` | 确认当前判定并前进 |
| `E` | 聚焦改分输入 |
| `Space` | 展开/收起证据面板 |
| `X` | 排除当前题（二次确认） |
| `Cmd+Z` | 撤销上一次复核命令（最近 50 步） |
| `Cmd+1`…`Cmd+0` | 直达各页面（复核页为 `Cmd+6`） |
| `Esc` | 关闭弹层或取消当前操作 |

单字母快捷键在文本输入态不触发；目标 ≥15 题/分钟（20 题样本、纯键盘）。

## 4. 命令与规则

| 命令 | 适用 | 规则 |
|---|---|---|
| 接受 | 标准 | 分数不变，状态「已人工复核」，写新修订 |
| 改分 | 标准 | 分数必须在 0 到满分之间且符合分值粒度；原因码必填（识别错误/答案键歧义/模型判错/部分给分/单位或精度/其他），备注可选 |
| 修文本重判 | 标准 | 先保存你修正的识别文本（人工修正），再重判生成新修订；重判期间该题锁定 |
| 题级排除 | 标准 | 该题不计入统计；需原因（缺考/无效/重复/超范围/其他） |
| 提交级排除 | 标准 | 整份提交移出统计与导出样本；需原因与备注 |
| 批量接受 | 标准 | 逐项事务；部分失败不回滚已成功项，失败项逐条列出 |
| 抽检通过 | 快速抽检 | 只写抽检结论与审计，判分状态不变 |
| 抽检不通过 | 快速抽检 | 弹窗询问重跑范围（默认单题、可选整卷），确认后发命令并审计 |
| 转标准复核 | 快速（单个或批量） | 以标准模式重判生成新修订；原快速记录保留 |
| 撤销/重做 | 两者 | 追加反向动作，不删除历史；进程重启后仍可撤销 |

并发与冲突：同一题在多个窗口同时操作时，后提交者因修订号过期被拒，输入保留、提示刷新；不会覆盖历史结果。

## 5. 改分与理由

- 改分只追加新修订，原始自动判定与旧修订仍可在历史中查看。
- 每次改分必须带原因码；审计记录操作者（固定 `local-teacher`）、时间、前后值与备注。
- 复核后的结果自动进入统计与导出；未复核项不会混入正式成绩。

## 6. 抽检重跑弹窗

- 触发：快速抽检判定不通过。
- 内容：原判定、抽检判定、差异摘要；范围单选「仅本题（默认）」或「整卷」。
- 确认：由复核服务发起重跑，写审计；整卷重跑生成整卷任务，其他题不被单题重跑覆盖。
- 取消：保持待复核，不自动重跑；不会静默通过。
- 重跑不直接改分，只产生新修订；导出需重新生成。

## 7. 撤销与导出后修改

- 撤销栈深度默认 50 步（可配 10–200）；撤销是追加反向动作，不改历史记录。
- 已导出后仍可复核/改分，但界面会提示「已导出，需要重新导出」；不会自动改写已生成的文件。

## 8. 效率建议

1. 先用过滤只看「冲突/不可判定」，再处理低置信度。
2. 键盘流：`J/K` 翻题，`Enter` 接受，只有真需要改的题才用 `E`。
3. 批量确认只用于你有把握的同质题（如客观题高置信度）。
4. 证据缺失的题不要凭印象确认；先修文本或转人工核对。
