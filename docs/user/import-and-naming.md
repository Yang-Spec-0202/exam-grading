# 导入与命名

> 状态：M10 文档初稿（计划中）。导入页与文件名匹配随 M3/M6 实现提供；本页描述目标行为，截图与按钮名称以发布版本为准。

## 1. 支持的文件

| 格式 | 处理方式 | 限制与注意事项 |
|---|---|---|
| JPG/JPEG、PNG | 直接解码进流水线 | 主路径；透明通道按白底合成 |
| HEIC/HEIF | 经 macOS 系统图像接口解码 | 系统解码器不可用时显式报「不支持」，不会静默跳过 |
| TIFF | 单页按单页，多页按文件内目录顺序拆页 | 多页不支持的编码取首帧并显式告警 |
| PDF | 逐页渲染为位图，原 PDF 同时入库以便复现 | 页序固定、不可重排；加密或损坏按文件级失败，不产生半页 |
| DOCX | **仅用于参考答案**（抽取段落/表格纯文本） | 公式对象跳过并计数；旧版 .doc 拒绝并提示另存 |

补充规则：

- 单批文件数上限默认 2000（超出在开始前拒绝）；PDF 拆页分辨率默认 300 DPI（可调 150–600）。
- PDF 默认透明背景，送 OCR 前会合成白底；加密 PDF 不支持，需先解密另存。
- 图片默认按文件名自然序；教师可在导入前重排页序（重排写审计，只改页号不改页面 id）。
- OCR 输入会被模型下采样到约 1MP：**密集小字页靠版面分块，不是提高 DPI 能解决**；把 PDF DPI 调到 600 不会改善小字识别。

## 2. 文件名就是学生身份（v1 唯一来源）

系统只认文件名（去扩展名后的 `source_stem`），不做 OCR 姓名兜底（默认关闭，可配置但需审批）。

**推荐命名**

- `张三.jpg`、`张三_期中数学.pdf`（姓名唯一时可命中）
- `20250103.jpg`、`20250103_张三.pdf`（学号命中更稳，尤其同班有重名）

**归一化后匹配**：去首尾空白、全半角统一、连续空白折叠、可解析的页码后缀会被去掉（如 `_p1`、`_p2`、`-第2页`）；再与名单的学号或姓名精确比对。归一化只处理格式差异，不做模糊匹配。

**未命中的后果**

- 默认进「未决」：不会自动判分，需要你在名单中检索并选定学生；候选按名单顺序展示，不会按相似度自动替你选。
- 即使把设置改为「自动归入名单外」，这类提交也只保留诊断、不自动出分，等你补名单或标记无效提交。
- 相机生成的文件名（如 `IMG_0032.jpg`）基本无法命中，多文件批次会整批进未决，建议导入前在访达中批量改名。

**选择文件时的提醒**：默认开启（`import.remind_naming`）。提醒只是提示，不会替你改名；应用**不会**修改或重命名你的文件。

## 3. 多页与多文件

- 一份提交 = 一个源文件；PDF 内的多页属于同一提交。
- 同一次导入出现同 stem 的多个图片且页码后缀可解析（如 `张三_p1.jpg`、`张三_p2.jpg`）时合并为一份；页码后缀无法解析时各自独立并记「分组可疑」，需要你合并。
- 页数超过试卷模板页数时，多余页不参与判分并进未决；缺页会让对应题目不可判定，整卷标记「不完整」。

## 4. 质量门控与拒收

导入前先做质量检查（模糊、曝光、倾斜、分辨率、高光/死黑等）。判定为「拒绝」的页不会进入识别，原图与质量记录仍保留：

| 原因码 | 含义 | 建议处理 |
|---|---|---|
| 模糊 | 拉普拉斯方差低于阈值 | 重拍（稳住手机、避免运动） |
| 欠曝/过曝 | 平均亮度越界 | 改善光线、避免闪光直射 |
| 倾斜 | 倾斜角超过上限 | 重拍或摆正纸张 |
| 分辨率 | 长边低于下限 | 提高拍摄分辨率或重新扫描 |
| 眩光/死黑 | 高光溢出或近黑占比过大 | 换角度避开反光 |
| 无行结构 | 空白或倒置页 | 检查是否拍错页/倒置 |

默认行为是「页级拒收、批次继续」，同提交其它页照常处理；你可以补拍后把该页追加到同一提交的指定页号。若改为「整批中止」，则未开始的文件不再派发、已完成的保留。

## 5. 去重与重复导入

- 资产级去重永远开启：同字节文件只存一份（内容寻址），不重复占磁盘。
- 同一批内的重复文件只处理一次，其余标记「同批重复」。
- 提交级判重：同一试卷同一班级下，新提交的页面哈希集合与既有提交重合 ≥80% 时判为「疑似重复提交」，默认弹窗询问（可关闭提示，但去重与幂等不受影响），不会自动建档。
- 重复导入是幂等的：同一输入重跑不会产生重复成绩。

## 6. 导入前的检查单

- [ ] 文件已按学生名或学号命名，无 `IMG_` 之类相机名
- [ ] 每个学生一份（多页用 PDF 或可解析页码后缀）
- [ ] 无模糊/过曝/缺页；补拍页已追加到正确提交
- [ ] 名单已更新，无重名未处理、无空学号
- [ ] 没有把不同试卷的作业混在同一批
